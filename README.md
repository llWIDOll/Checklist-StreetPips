# Checklist StreetPips

Proyecto simple para el checklist operativo diario de StreetPips.

## Cómo usar

1. Ejecuta `npm install`.
2. Ejecuta `npm start`.
3. Abre `http://localhost:8080/checklist_streetpips.html` en tu navegador.

## Notas

- El archivo principal es `checklist_streetpips.html`.
- Usa `npm run serve` como alias de `npm start`.
